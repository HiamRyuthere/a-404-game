system note // 404

404 is an HTTP status code. The server answered — but nothing lives at the URL you asked for.

Usual reasons:

  • The page was deleted or renamed.
  • The URL has a typo or an extra slash.
  • A link pointing here is out of date.
  • The content is private, so the server acts like it never existed.

It isn't 500 (the server crashed) and isn't 403 (the page exists, you're just not allowed in). 404 is in the 4xx family: the client asked for something that isn't there.

Next: check the URL, go home, or use search. If you came from a link on this site, that link is broken — worth reporting.
